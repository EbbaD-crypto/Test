# Varumärkesfärger

Sparade från dina önskemål och inspirationsbilder. Hex-koderna är startvärden. Justera när vi låst varumärket.

| Namn | Hex | Användning |
|---|---|---|
| Smörgult (butter) | `#F1DFA0` | ljus accent, etiketter, bakgrundspapper |
| Duvblått (dove) | `#A9BCCB` | kort, flikar, lugn kontrast |
| Kastanj | `#8C4A34` | accent, detaljer, tryckfärg |
| Kakao | `#6E4A36` | text på ljust papper, mörk accent |
| Pastell varmrosa | `#E7B6A8` | mjuk accent, silkespapper |
| Djup rosa | `#C98272` | sparsam accent |
| Kräm / ecru | `#F4ECD8` | grundpapper |
| Kraft | `#C9A57A` | kraftpapper, mappar |
| Salvia | `#A3AE8C` | botaniskt, blad |
| Bläck | `#3A2C25` | all brödtext och namn |

## Typografi (nuvarande)
- Namn och rubriker: Libre Caslon Text
- Kursiv brödtext: Libre Caslon Text Italic
- Arkivetiketter och ursprung: Courier Prime
- Uttal (IPA): Gentium Book Plus Italic
